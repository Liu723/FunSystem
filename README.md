# FunSystem - 快手反应训练营

这是一个使用 **原生 HTML/CSS/JavaScript** 搭建的小游戏界面。  
支持一条命令快速启动本地服务（`npm start`）。

## 玩法
1. 点击「开始挑战」，游戏时长为 30 秒。
2. 点击场地内随机移动的红色目标，每命中一次 +1 分。
3. 点击空白区域会记为失误。
4. 可通过滑杆自由调节红球跳动速度（数值越小越快）。
5. 每局结束会记录成绩，并在历史榜单中按分数排名。

## 快速运行
### 方式一（推荐）
```bash
npm start
```
然后访问：`http://localhost:4173`

### 方式二
直接用浏览器打开 `index.html`。
